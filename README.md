# Yomna Ehab portfolio

- This is the final version of the website, waiting for the testing phase.

## Run locally

- Copy `.env.example` to `.env` and add your Supabase project URL, server secret
  key, and a unique admin password.
- Run `npm start` and open `http://localhost:3000`.

The local server reads and writes portfolio content and inquiries in Supabase.
See [database/README.md](database/README.md) for setup details.
